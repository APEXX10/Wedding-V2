# เว็บการ์ดแต่งงาน — Saranya & Papatsapon

เว็บ one-page ที่ทำจากการ์ด Save the Date ทั้ง 3 ใบ (ป่าสน · ภาพถ่ายแหวน · หุบเขาดอกไม้)

## วิธีเปิด

ดับเบิลคลิก `index.html` ได้เลย (ไม่ต้องมีเซิร์ฟเวอร์)
หรือถ้าอยากรันเป็นเว็บเซิร์ฟเวอร์:

```bash
npx -y http-server C:/Users/jetsada.k/SKY -p 8199 -c-1
```

แล้วเปิด http://localhost:8199

## โครงสร้าง

```
SKY/
├─ index.html                 โครงหน้าเว็บทั้งหมด
├─ assets/css/style.css       ดีไซน์ · สี · ฟอนต์ · responsive
├─ assets/js/main.js          นับถอยหลัง · ปฏิทิน · ไลท์บ็อกซ์ · RSVP
└─ assets/img/
   ├─ card-forest / card-rings / card-valley .jpg   การ์ดเต็มใบ → ใช้ในแกลเลอรีเท่านั้น
   ├─ card-rings-original.jpg                       การ์ดใบที่ 3 ก่อนลบแถบ THEM CODE (สำรองไว้)
   ├─ art-forest.jpg / art-valley.jpg               ภาพวาดที่ตัดตัวอักษรออกแล้ว → ใช้เป็นพื้นหลัง
   └─ photo-couple.jpg                              ภาพถ่ายคู่ที่ตัดกรอบ+ตัวอักษรออก
```

> ⚠️ **ห้ามเอา `card-*.jpg` ไปทำพื้นหลัง** เพราะการ์ดมีตัวหนังสือของมันเองอยู่แล้ว
> พอวางข้อความ HTML ทับจะซ้อนกันสองชั้น (เคยเกิดมาแล้ว) — พื้นหลังต้องใช้ `art-*.jpg` เท่านั้น
> ถ้าจะตัดรูปใหม่ ใช้สคริปต์ `crop-art.ps1`

## ต่อฟอร์มตอบรับเข้า Google Form

ตอนนี้โค้ดพร้อมแล้ว แต่ยังไม่รู้ว่าจะส่งไปฟอร์มไหน — ต้องกรอก 6 ค่านี้ก่อน
ระหว่างที่ยังไม่กรอก กดปุ่มส่งจะขึ้นข้อความว่า "ยังไม่ได้ตั้งค่า Google Form"

### 1) สร้างฟอร์มใน Google Form

สร้างคำถาม **5 ข้อ** ให้ตรงกับช่องในเว็บ (ชื่อคำถามตั้งเป็นอะไรก็ได้ แต่ชนิดต้องตรง):

| # | คำถาม | ชนิด |
|---|-------|------|
| 1 | ชื่อ | ข้อความคำตอบสั้น |
| 2 | นามสกุล | ข้อความคำตอบสั้น |
| 3 | เบอร์ติดต่อ | ข้อความคำตอบสั้น |
| 4 | จำนวนผู้ร่วมงาน | ข้อความคำตอบสั้น |
| 5 | คำอวยพร | ย่อหน้า |

> ⚠️ **อย่าตั้งช่องไหนเป็น "จำเป็นต้องกรอก" (Required) ยกเว้นข้อ 1**
> เว็บปล่อยให้เว้นว่างได้ทุกช่องยกเว้นชื่อ ถ้าฟอร์มบังคับกรอกแล้วเว็บส่งค่าว่างมา **Google จะตีกลับทั้งใบ**

จากนั้นกดแท็บ **Responses → เชื่อมกับ Google Sheets** เพื่อให้คำตอบไหลเข้าชีตอัตโนมัติ
และกดปุ่ม **Publish** มุมขวาบน ตั้งสิทธิ์ผู้ตอบเป็น **"ทุกคนที่มีลิงก์"** ไม่งั้นคนนอกส่งไม่ได้

### 2) เอา formId

เปิดฟอร์มแบบที่คนอื่นเห็น (ปุ่ม "ส่ง" → ไอคอนลิงก์) URL จะหน้าตาแบบนี้:

```
https://docs.google.com/forms/d/e/1FAIpQLSd7xxxxxxxxxxxxxxxxxxxx/viewform
                                  └──────────── formId ────────────┘
```

### 3) เอา entry id ของแต่ละช่อง

ในหน้าแก้ไขฟอร์ม กดจุดสามจุดมุมขวาบน → **รับลิงก์ที่กรอกไว้ล่วงหน้า**
กรอกค่าอะไรก็ได้ลงทุกช่อง (เช่น 1, 2, 3, 4, 5) แล้วกด **รับลิงก์ → คัดลอกลิงก์**
ลิงก์ที่ได้จะมีเลขของทุกช่องอยู่:

```
...viewform?usp=pp_url&entry.1234567890=1&entry.987654321=2&entry.5555=3&...
             ช่องที่ 1 ─┘                  ช่องที่ 2 ─┘
```

### 4) เอาไปใส่ใน `assets/js/main.js` บนสุด

```js
const RSVP_FORM = {
  formId: '1FAIpQLSd7xxxxxxxxxxxxxxxxxxxx',
  fields: {
    firstName: 'entry.1234567890',   // ชื่อ
    lastName:  'entry.987654321',    // นามสกุล
    tel:       'entry.5555',         // เบอร์ติดต่อ
    guests:    'entry.6666',         // จำนวนผู้ร่วมงาน
    wish:      'entry.7777',         // คำอวยพร
  },
};
```

### 5) ทดสอบ

เปิดเว็บ กรอกชื่อทดสอบแล้วกดส่ง → เว็บจะเปลี่ยนเป็นข้อความขอบคุณ
แล้วไปดูใน Google Sheet ว่าแถวเข้าครบทุกช่องไหม

> ⚠️ **Google ไม่ส่ง CORS header กลับมา** เว็บจึงอ่านผลลัพธ์ไม่ได้ (ใช้ `mode: 'no-cors'`)
> ⇒ ถ้า entry id ผิดสักช่อง หน้าเว็บจะยังขึ้น "ขอบคุณ" เหมือนเดิม แต่ชีตจะไม่มีข้อมูลช่องนั้น
> **จึงต้องยิงทดสอบจริงแล้วเปิดชีตดูทุกช่อง** อย่าเชื่อข้อความบนหน้าเว็บอย่างเดียว

## แก้ข้อมูลงาน

แก้ที่เดียวบนสุดของ `assets/js/main.js`:

```js
const WEDDING = {
  start: '2026-11-22T07:09:00+07:00',   // ฤกษ์พิธี (ใช้กับนับถอยหลัง + ปฏิทิน)
  end:   '2026-11-22T12:00:00+07:00',   // เวลาสิ้นสุดโดยประมาณ ← ใส่ไว้ก่อน แก้ได้
  venue: 'นาคลองหลวง บูทีค รีสอร์ท (Na Klongluang Boutique Resort)',
};
```

ข้อความบนหน้าเว็บ (คำเชิญ · รายการกำหนดการ · การแต่งกาย) แก้ตรง ๆ ใน `index.html`

## หมายเหตุ

- ปุ่มแผนที่ใช้ Google Maps แบบ**ค้นหาชื่อรีสอร์ท** ถ้าอยากได้หมุดเป๊ะ ให้เอาลิงก์หมุดจริงมาแทน `href` ในส่วน `#detail`
- รายการกำหนดการตอนนี้มีแค่ที่ปรากฏบนการ์ดจริง (07.09 น.) ที่เหลือเติมได้ตามจริง
- **ความคมของภาพ** — จัดการไว้ 3 ชั้น:
  1. CSS จำกัดความกว้างแถบภาพไม่ให้เกินขนาดจริงของไฟล์ (`max-width` ของ `.hero__art` / `.detail__art`)
  2. มีไฟล์ `@2x` สำหรับจอที่ `devicePixelRatio > 1` (Windows scaling 125%+, Retina, มือถือ)
     สลับให้อัตโนมัติด้วย `@media (min-resolution:1.2dppx)` ใน `style.css` และ `srcset` ของรูปคู่บ่าวสาว
     สร้างไฟล์ @2x ด้วย `make-hidpi.ps1` (ขยาย HighQualityBicubic + unsharp mask)
  3. ทุกไฟล์บันทึกที่ quality สูง ไม่บีบอัดทับซ้ำ

  > การขยายภาพไม่ได้เพิ่มรายละเอียดที่ไม่มีในต้นฉบับ — ไฟล์การ์ดที่มีกว้างแค่ ~1,100 px
  > (ผ่านการบีบอัดจาก LINE มาแล้ว) ถ้าอยากคมกว่านี้จริง ๆ ต้องขอไฟล์ต้นฉบับจากคนออกแบบการ์ด
  > แล้ววางทับใน `assets/img/` → รัน `crop-art.ps1` → รัน `make-hidpi.ps1` → แก้ `max-width` ให้ตรงขนาดใหม่
- ฟอนต์โหลดจาก Google Fonts → ตอนเปิดครั้งแรกควรต่อเน็ต (ถ้าออฟไลน์จะ fallback เป็นฟอนต์ระบบ)
